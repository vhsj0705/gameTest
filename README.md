# 5천만 분의 1 — 대한민국 인생 시뮬레이터

[80억 분의 1](https://1in8b.life/ko/)처럼, 무작위로 태어나 한 사람의 일생을 살아 보는 인생 시뮬레이션이에요.
세계 대신 **대한민국(1940~2025년생)** 한정이고, 그 시대의 실제 통계와 역사가 선택지에 반영돼요.

## 실행

빌드 도구가 없어요. `index.html`을 브라우저로 열면 돼요. (로컬 서버가 필요하면 `npx serve .`)

## 시대가 반영되는 부분

| 구분 | 반영 내용 |
|---|---|
| 수명·사망 | 통계청 생명표의 연도별 기대수명·영아사망률에 맞춰 보정한 사망 확률(`js/mortality.js`). 한국전쟁·베트남 파병·코로나 시기 추가 위험 |
| 학교 | 중·고교·대학 진학률의 연도별 변화(대학 1970년 약 27% → 2008년 약 84%), 중학 무시험(1969)·고교 평준화(1974) 안내 |
| 일자리 | 호황(1980~96)·IMF(1997~99)·취업난 시기별 취업 난이도, 파독 광부·간호사(1963~77), 중동 건설(1975~86), 구조조정, 정년(55→60세) |
| 가족 | 연도별 평균 초혼 나이, 중매(1990년 이전)·소개팅, 합계출산율(1970년 4.5명 → 2023년 0.72명), 결혼 의향 감소, 이혼 |
| 주거 | 집값/소득 배수와 집값 흐름(1987~91 급등, 1992~98 하락, 2014~21 급등, 2022~23 하락), 대출 금리 |
| 시대 사건 | 4·19, 한국전쟁, 베트남 파병, 5·18, 6월 항쟁, IMF·금 모으기, 카드 대란, 촛불, 코로나, 영끌 등 선택 사건 |
| 건강 | 건강보험 시행(1977 일부, 1989 전 국민)에 따라 치료비가 달라짐, 연금(1988)·기초연금(2014) |
| 2026년 이후 | 통계청 장래인구추계를 참고한 **가상 전망**으로 표시 |

## 자료 출처와 한계

- 통계청 생명표(기대수명), 국가통계포털(KOSIS), 교육부 교육기본통계, 한국은행 경제통계, 통계청 혼인·출생통계 등 공개 자료의 **추세를 근사**했어요. 개발 중 웹 검색으로 확인한 값: 기대수명(2000년 약 76.0세, 2010년 약 80.7세, 2014년 82.4세), 대학진학률(1970년 약 27%, 1990년 33.2%, 2000년 68.8%, 2008년 83.8%), 초혼 연령(1995년 남 28.4·여 25.3세), 1998년 성장률 -5.1%, 암 사망원인 1위(1983년 집계 이후).
- 검색으로 못 찾은 수치(1960~80년대 일부 기대수명, 합계출산율 등)는 알려진 추세로 채웠어요. 정확한 값이 필요하면 KOSIS에서 확인하세요.
- 개인의 선택과 결과는 확률로 정해지는 **가상의 이야기**예요. 실제 사건·통계를 반영했지만 개인의 삶을 단정하지 않아요.

## Godot 인생 기록 재생기

결과 화면의 **Godot 재생용 기록 저장**으로 받은 JSON을 `godot/` 프로젝트(Godot 4.4+)에서 열면, 기억에 남긴 순간과 주요 사건을 장면 그래픽으로 재생하고 인생을 요약해 줘요. 자세한 내용은 [godot/README.md](godot/README.md).
