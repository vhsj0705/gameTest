# 인생 기록 재생기 (Godot 4)

웹 게임에서 한 삶을 마친 뒤 나온 기록을 불러와, **중요한 순간을 골라 장면 그래픽과 함께 재생**하고 마지막에 **인생 요약**을 보여 줘요. 그림은 모두 코드로 그려서 별도 이미지 파일이 없어요.

## 사용 방법
1. 웹 게임(`index.html`) 결과 화면에서 **Godot 재생용 기록 저장**을 눌러 JSON을 받아요.
2. Godot 4.4 이상으로 이 폴더(`godot/`)를 열고 실행해요. (`godot --path godot`)
3. 화면의 **기록 열기**로 JSON을 고르거나, 파일을 창에 끌어다 놓아요. 아무것도 열지 않으면 `sample_life.json` 예시가 재생돼요.

조작: 일시정지/재생, ◀ ▶ 장면 이동, 1×·2×·4× 속도, 아래 막대를 눌러 원하는 장면으로 이동.

## 중요한 순간은 어떻게 고르나요?
`scripts/highlights.gd`가 기록의 각 줄에 점수를 매겨요. ★(기억에 남긴 순간) +12, 선택 +5, 좋은·나쁜 일 +4, 결혼·졸업·취업·내 집 같은 이정표 +4. 출생과 죽음은 항상 넣고, 같은 장면은 최대 2번, 같은 해는 1번만 넣어 최대 14장면으로 요약해요.

## 장면 그래픽
`scripts/stage.gd`에 장면 25종(출생·학교·졸업·공장·사무실·농촌·상경·전쟁·군 복무·거리 시위·외환위기·해외·결혼·가족·집·병원·사고·은퇴·환호·상실·친구·재난·감염병·뉴스·죽음)이 있어요. 기록 문장의 키워드로 장면이 정해져요. 1975년 이전 사건은 빛바랜 사진 느낌으로 보여요.

## 개발용 옵션
```bash
godot --path godot -- --record=파일.json --shots=저장폴더 --speed=4 --max=14
```
`--shots`는 장면마다 스크린샷을 저장하고 끝나면 종료해요.
